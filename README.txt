THE NOTH AI — النسخة التجريبية المطوّرة
1) افتح index.html لمعاينة التطبيق.
2) للنشر عبر GitHub Pages: أنشئ/افتح مستودع GitHub، وارفع index.html وmanifest.json إلى جذر المستودع.
3) Settings > Pages > Deploy from a branch > main > /(root) > Save.
4) بعد ظهور رابط github.io افتحه في Safari، ثم مشاركة > إضافة إلى الشاشة الرئيسية.

ملاحظات: بيانات النموذج تحفظ محلياً على نفس المتصفح. البحث الحقيقي عن المطاعم، تحليل الصور بالذكاء الاصطناعي، التحقق عبر SMS والإشعارات المجدولة تحتاج خدمات وربطاً فعلياً، وهي ليست مفعّلة في هذه النسخة.
